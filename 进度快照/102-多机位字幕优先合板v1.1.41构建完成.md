## 已完成内容
- 完成视频目录递归导入入口收口：
  - 目录按钮和拖拽目录都包含下级目录。
  - 拖拽目录关闭软链接跟随。
  - 重复导入同一目录不会重复入库。
- 完成字幕优先多机位布局：
  - 字幕相似度、字幕锚点数、偏移中位数、偏移稳定度共同判断多机位。
  - 最长视频作为基准机位。
  - 短机位按字幕锚点偏移叠到上方轨道。
  - 短机位早于基准时整体右移，不裁切视频。
- 完成轻量音频辅助：
  - 仅低置信字幕结果时启用。
  - 使用 FFmpeg 提取低采样率 PCM。
  - 使用音频能量、过零率、能量变化做局部交叉相关确认。
  - 不让音频成为主判定。
- 完成时间线运行时模型与预览：
  - `TimelineData` 增加多机位组、角色、轨道、置信度、锚点数、音频辅助状态和说明。
  - 时间线总时长改为取最大结束点，避免重叠素材被重复累加。
  - 预览页展示多机位判断依据。
- 完成 XML/FCPXML 多轨导出：
  - xmeml 按 `videoTrackIndex` 输出多条视频轨。
  - FCPXML 使用绝对时间，并为上方机位写入 `lane`。
  - 多机位视频导出后不再串联，而是在时间线上重叠。
- 已生成 Windows release 发布产物。

## 具体修改的代码前后对比

### 目录导入入口

修改前：
```dart
await DatabaseService.insertMediaFiles(mediaFiles);
```

修改后：
```dart
await _importMediaFiles(mediaPaths, restrictToType: mediaType);
```

### 多机位布局接入

修改前：
```dart
final preparedVideos = await _refreshLayouts(
  projectId,
  videos,
  MediaType.video,
);
```

修改后：
```dart
var preparedVideos = await _refreshLayouts(
  projectId,
  videos,
  MediaType.video,
);

final multicamLayout = await VideoMulticamLayoutService.refreshVideoLayouts(
  projectId,
  preparedVideos,
  allowAudioAssist: true,
);
preparedVideos = multicamLayout.updatedVideos;
```

### 导出时间计算

修改前：
```dart
videoPositions[t.videoFileId] = currentFrame;
currentFrame += _msToFrames(t.videoDurationMs);
```

修改后：
```dart
final videoPositions = _videoStartFrames(timelineList);
final totalDuration = _timelineDurationFrames(timelineList);
```
