## 已完成内容

### 1. 已新增 macOS 环境自动补齐脚本
- 新增：
  - `tool/ensure_macos_environment.py`
- 脚本能力：
  - 检查本机 Flutter 版本，当前要求 `Flutter 3.44.2 stable`
  - 如果本机已有正确 Flutter，则直接复用
  - 如缺失或版本不匹配，可从 Flutter 官方 release manifest 下载对应 SDK 到 `.toolchain/flutter`
  - 自动下载 macOS Intel 静态 FFmpeg/FFprobe release
  - 写入 FFmpeg manifest，记录下载 URL、版本和 SHA256
  - 支持把 FFmpeg runtime 安装到指定发布目录

### 2. 已自动下载并补齐 FFmpeg runtime

- `.toolchain/` 已加入 `.gitignore`，不提交二进制缓存。

### 3. 已让发布脚本自动安装 runtime
- 已更新：
  - `tool/prepare_clean_release.py`

  - `python3 tool/ensure_macos_environment.py --skip-flutter --install-runtime-to <release_dir>`

  - `dist/v1.1.24/runtime/ffmpeg/macos-x64/bin/ffmpeg`
  - `dist/v1.1.24/runtime/ffmpeg/macos-x64/bin/ffprobe`

### 4. 已让应用优先使用随包 FFmpeg
- `AppSettings.defaultFfmpegPath` 在 macOS 下优先查找：
  - `.app` 同级 `runtime/ffmpeg/macos-x64/bin`
  - `.app` 同级 `runtime/ffmpeg/macos-arm64/bin`

  - `/usr/local/bin`
- 读取旧配置时，如果 macOS 下发现旧 Windows 路径如 `G:\...`，会自动回落到当前平台默认值。
- `FfmpegService` 已支持传入 `ffmpeg` 可执行文件路径或目录路径。
