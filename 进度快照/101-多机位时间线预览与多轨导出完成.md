# 进度快照 101 - 多机位时间线预览与多轨导出完成

## 已完成内容
- 扩展 `TimelineData` 运行时字段：
  - `videoTrackIndex`
  - `multicamGroupId`
  - `multicamRole`
  - `multicamConfidence`
  - `multicamAnchorCount`
  - `multicamAudioAssistStatus`
  - `multicamNote`
- `AudioAlignService.buildTimeline` 现在会根据视频布局附加多机位轨道信息。
- `TimelineState.totalDurationMs` 改为取最大时间线结束点，避免多机位重叠时总时长被简单相加。
- `TimelinePreview` 显示多机位角色、视频轨、置信度、锚点数、音频辅助状态和说明。
- `ExportService.exportXmeml` 改为按 `timelineStartMs` 绝对时间放置视频，并按 `videoTrackIndex` 输出多条视频轨。
- `ExportService.exportFcpxml` 改为按 `timelineStartMs` 绝对时间放置视频，上方机位通过 `lane` 输出。
- 新增导出测试，验证多机位视频不会串联，而是上下轨重叠。
- 新增时间线构建测试，验证多机位信息进入 `TimelineData`。

## 具体修改的代码前后对比

### `lib/providers/timeline_provider.dart`

修改前：
```dart
int get totalDurationMs =>
    timelineList.fold(0, (sum, item) => sum + item.videoDurationMs);
```

修改后：
```dart
int get totalDurationMs => timelineList.fold(
  0,
  (currentMax, item) =>
      item.timelineEndMs > currentMax ? item.timelineEndMs : currentMax,
);
```

### `lib/services/export_service.dart`

修改前：
```dart
int currentFrame = 0;
final videoPositions = <String, int>{};
for (final t in timelineList) {
  videoPositions[t.videoFileId] = currentFrame;
  currentFrame += _msToFrames(t.videoDurationMs);
}
```

修改后：
```dart
final videoPositions = _videoStartFrames(timelineList);
final totalDuration = _timelineDurationFrames(timelineList);
```

### `lib/widgets/timeline_preview.dart`

新增显示：
```dart
if (timeline.isMulticam)
  _Meta(label: '多机位', value: timeline.multicamRole),
if (timeline.isMulticam)
  _Meta(label: '视频轨', value: 'V${timeline.videoTrackIndex + 1}'),
```
