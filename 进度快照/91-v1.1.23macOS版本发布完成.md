### 2. 已适配 macOS 路径与外部工具查找
- `AppSettings` 默认路径改为平台感知：
  - Windows 保留 `G:\data\app\DIT\ffmpeg`
  - macOS 优先 `/opt/homebrew/bin`，其次 `/usr/local/bin`
  - macOS 下 `sherpa-onnx` 默认不再写死 Windows 路径
- `FfmpegService` 已按平台查找：
  - Windows: `ffmpeg.exe` / `ffprobe.exe`
  - macOS: `ffmpeg` / `ffprobe`
- 新增跨平台文件名解析，兼容 `/` 与 `\` 分隔符，修复 macOS 下读取旧 Windows 风格路径时文件名显示/匹配异常的问题。

### 3. 已调整 macOS 发布数据目录
- macOS 版运行数据不再写入 `.app/Contents/MacOS/data`
- 改为与 `.app` 同级：
  - `dist/v1.1.23/asr_tools.app`
  - `dist/v1.1.23/data/config/asr_tools_settings.json`
  - `dist/v1.1.23/data/database/asr_tools.db`
  - `dist/v1.1.23/data/projects`
  - `dist/v1.1.23/data/temp`
- 避免修改签名后的 `.app` bundle 内容。
